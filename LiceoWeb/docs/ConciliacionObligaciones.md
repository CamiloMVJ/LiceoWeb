# Funcionalidad retirada

Desde la migración 025 no se trasladará información del sistema de escritorio. Las conciliaciones y su transición fueron retiradas. No ejecutar las instrucciones de versiones anteriores.

Consultar [RetiroConciliaciones.md](RetiroConciliaciones.md) para actualizar una base existente y [InstalacionDesdeCero.md](InstalacionDesdeCero.md) para una instalación nueva. Los cortes de caja continúan en [CortesYGraficos.md](CortesYGraficos.md).
